# AETHER BLADE — 聖樹傳說 (PixiJS v8 GPU 引擎版)

沿用《聖樹傳說》完整 10 房間大地圖與古神殿解謎邏輯（紅藍水晶、聖火法杖點燈、森林道具屋、推箱機關、妖精聖泉、炎核守衛 Boss），將渲染管線升級為 **PixiJS v8**（GPU Sprite Pooling、森林耶穌光束、空間折射震波濾鏡 ＋ 9-tap Bloom ＋ 即時 GPU 遙測）。
